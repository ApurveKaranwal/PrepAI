# interview-platform

These are the features that we are going to have in our platform:

1.  user uploads its resume and the projects github link which are present in resume. Our AI will read the entire resume and scrape the entire project from Github and then will ask questions regarding concepts (what are Promises) and also code snippets (const promise = new Promise(resolve, reject) what is meaning is this statement). and so on...
    
2.  there will be a feature of voice to voice interview, we can use sarvam tts model for taking the interview and in the end tell the user about the strengths and weakness based on the interview. This will affect the level of questions asked in the next interview session.
    
3.  The data extracted from resume can be used to find suitable jobs and internships. We can use Bots that auto apply for those role and notify the user via whatsapp/ Telegram (we need to enter how much money we wants per month).
    
4.  resume analyser, scans the resume and tells the ATS score, weak and strong points and how to improve it even more according to the job role he is looking for.
    
5.  Test feature: like user enter he wants to appear for amazon, then a test will be taken where difficult questions shall be asked from the projects he have made. We can also include a DSA round based on previous applicants experience, like what pattern is repeating.
